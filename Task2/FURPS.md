# Task 2

| Код  | Требования                                                                     | Комментарий                                                                                                                                 |
|------|--------------------------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------|
| **F** | **Функциональные (Functionality)**                                               | **Что система должна делать**                                                                                                               |
| F-01 | Отображение списка доступных депозитов с актуальными ставками на сайте банка.  | Для неавторизованных (новых) пользователей.                                                                                                 |
| F-02 | Возможность подачи заявки на депозит через сайт (сбор ФИО и номера телефона).   | Для новых клиентов, нужно шифрование хранимых перс. данных.                                                                                                                         |
| F-03 | Передача данных заявки с сайта в систему кол-центра.                             | Для последующей обработки менеджером, нужно шифрование хранимых перс. данных.                                                                                                       |
| F-04 | Отображение списка доступных депозитов с актуальными и персональными ставками в Интернет-банке. | Для авторизованных (существующих) клиентов.                                                                                  |
| F-05 | Возможность подачи заявки на открытие депозита в ИБ (выбор счета, ввод суммы).   | Для существующих клиентов.                                                                                                                  |
| F-06 | Подтверждение операции подачи заявки в ИБ с помощью СМС-кода.                  |  |
| F-07 | Возможность для сотрудников бэк-офиса управлять ставками по депозитам. |  |
| F-08 | Обработка заявки на депозит менеджером бэк-офиса.                                | |
| F-09 | Подтверждение условий депозита менеджером в АБС банка.                           | Интеграция с АБС.                                                                                                    |
| F-10 | Отправка СМС-уведомления клиенту после подтверждения ставки менеджером.           | Уведомление о промежуточном статусе.                                                                                                        |
| F-11 | Отправка СМС-уведомления клиенту после фактического открытия депозита в АБС.       | Уведомление о завершении процесса.                                                                                                          |
| **U** | **Удобство использования (Usability)**                                          | **Насколько легко и приятно пользоваться системой**                                                                                          |
| U-01 | Интерфейс подачи заявки на сайте и в Интернет-банке должен быть интуитивно понятным и удобным. | Требование "максимально удобный интерфейс".                                                                                         |
| U-02 | Визуальное оформление интерфейсов должно соответствовать принятой в банке системе дизайна. | Использование корпоративных цветов, шрифтов, брендированных элементов.                                                              |
| **R** | **Надёжность (Reliability)**                                                    | **Насколько стабильно и корректно система работает**                                                                                       |
| R-01 | Обеспечение шифрования трафика при передаче данных с сайта банка.                | Защита чувствительных данных новых клиентов (ФИО, телефон).                                                                                 |
| R-02 | Обеспечение шифрования трафика при передаче данных в Интернет-банке.             | Защита данных существующих клиентов.                                                                                                        |
| R-03 | Целевая доступность сервисов подачи заявок (сайт, ИБ) - 99.9%.                 | Требование бизнеса к высокой доступности.                                                                                                   |
| R-04 | Обеспечение работоспособности сервисов 24/7.                                    | Система должна быть доступна круглосуточно.                                                                                                 |
| R-05 | Реализация механизма переключения на резервный ЦОД для сервисов ИБ.              | Минимизация времени простоя при сбоях в основном ЦОД.                                                                                      |
| **P** | **Производительность (Performance)**                                           | **Насколько быстро система работает**                                                                                                      |
| P-01 | Время отклика интерфейсов пользователя на операции должно быть минимальным (цель - миллисекунды). | Требование "максимально быстрый отклик".                                                                             |
| P-02 | Оптимизация загрузки справочных данных для сокращения времени отклика. | Устранение текущих проблем с производительностью, влияющих на UX.                                                             |
| P-03 | Система должна поддерживать горизонтальное масштабирование.          | Для обеспечения производительности и доступности при росте нагрузки.                                                                      |
| **S** | **Поддерживаемость (Supportability)**                                          | **Насколько легко систему поддерживать и развивать**                                                                                       |
| S-01 | Разработка технической документации на реализованную функциональность.         | Для упрощения дальнейшего расширения и поддержки системы.                                                                                    |
| **+R**| **+ Ограничения (Restrictions / Constraints)**                                  | **Факторы, ограничивающие выбор решений**                                                                                                   |
| +R-01| MVP реализует только подачу заявки; полное открытие онлайн для новых клиентов невозможно без визита в офис. | Регуляторное ограничение (идентификация).                                                                                   |
| +R-02| Следует избегать доработок ядра системы силами подрядчика.                  | Организационное ограничение / пожелание.                                                                                                    |
| +R-03| Предпочтительное использование существующих СУБД: MS SQL, Oracle.              | Технологическое ограничение / стандарт банка.                                                                                             |
| +R-04| Новые технологии должны быть совместимы с существующими платформами и иметь внутреннюю экспертизу. | Технологическое и ресурсное ограничение.                                                                                    |
